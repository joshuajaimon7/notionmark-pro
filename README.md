# NotionMark Pro 📑

> **Clip clean web articles, documentation, and tables to Markdown with YAML frontmatter for Notion and Obsidian.**  
> Minimalist, fast, and 100% private.

🌐 **Live Website:** [https://joshuajaimon7.github.io/notionmark-pro/](https://joshuajaimon7.github.io/notionmark-pro/)  
🔒 **Privacy Policy:** [https://joshuajaimon7.github.io/notionmark-pro/privacy.html](https://joshuajaimon7.github.io/notionmark-pro/privacy.html)

---

## Features
- **Readability & Junk Stripper:** Automatically removes ads, cookie banners, navigation, and tracking UTM tags from links.
- **HTML Table to Markdown:** Converts complex web tables into aligned Markdown tables (`| Col 1 | Col 2 |`).
- **Obsidian YAML Frontmatter:** Generates title, author, source URL, date, reading time, and tags.
- **Executive 3-Bullet Takeaways:** Automatically extracts key insights at the top of every clipped note.
- **Reader Cinema Mode:** Distraction-free reading overlay on any website.
- **100% On-Device:** Operates completely inside your browser. Zero cloud tracking or data collection.

## Local Installation (Developer Mode)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/joshuajaimon7/notionmark-pro.git
   ```
2. Open **Google Chrome** and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** (top-left) and select the `04-notionmark-pro` folder.
5. Open any web article (or open `demo-test.html`) and click the NotionMark icon in your toolbar.
